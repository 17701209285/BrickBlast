# BrickBlast 震动逻辑说明

## 1. 结论

当前目标工程里的反馈逻辑已经拆成两层：

- `Screen Shake`：屏幕抖动
- `Vibration / Haptic`：设备震动

两者分别由不同开关控制：

- 屏幕抖动开关：`FeedbackSettings.IsScreenShakeEnabled`
- 设备震动开关：`FeedbackSettings.IsVibrationEnabled`

对应代码位置：

- `Client/Assets/Scripts/UI/FeedbackSettings.cs`
- `Client/Assets/Scripts/UI/ScreenShakeController.cs`
- `Client/Assets/Scripts/UI/HapticController.cs`

## 2. 触发入口

棋盘每次完成一次碰撞结算后，会生成一份 `ChessBoardImpactSummary`，再通过 `UIChessBoard.ImpactResolved` 事件抛出。

事件中包含的关键字段：

- `DestroyedBrickCount`：本次结算中被打掉的砖块数量
- `TriggeredSpecialType`：本次是否触发了特殊块

`ScreenShakeController` 订阅了这个事件，所以它既负责屏幕抖动，也负责决定是否触发设备震动。

涉及文件：

- `Client/Assets/Scripts/UI/UIChessBoard/UIChessBoard.cs`
- `Client/Assets/Scripts/UI/UIChessBoard/ChessBoardImpactSummary.cs`
- `Client/Assets/Scripts/UI/ScreenShakeController.cs`

## 3. 屏幕抖动逻辑

屏幕抖动只在以下条件满足时触发：

- `FeedbackSettings.IsScreenShakeEnabled == true`
- `ShakeOnMultiDestroy == true`
- `DestroyedBrickCount >= MinimumDestroyedBricksForShake`

当前默认阈值：

- `MinimumDestroyedBricksForShake = 2`

强度映射规则：

- 当消除数从 `2` 增长到 `8` 时
- 抖动强度从 `24` 线性增加到 `52`
- 抖动时长从 `0.22s` 线性增加到 `0.32s`

参数定义位置：

- `Client/Assets/Scripts/UI/ScreenShakeConstants.cs`

## 4. 设备震动逻辑

### 4.1 普通消除

如果这次结算没有触发特殊块，则按普通消除逻辑处理：

- `DestroyedBrickCount < 2`：不震动
- `DestroyedBrickCount >= 2`：触发一次瞬时震动

瞬时震动会把消除数映射成两组参数：

- `intensity`：`0.3 -> 1.0`
- `sharpness`：`0.55 -> 1.0`

随后 `HapticController.Play(float intensity, float sharpness)` 会把它们转成设备脉冲：

- 时长：大约 `42ms -> 18ms`
- 振幅：大约 `72 -> 255`

### 4.2 特殊块

如果触发了特殊块，则优先走专用震动模式：

- `HorizontalBlast` / `VerticalBlast`
  - 调用 `PlayMultiRow()`
  - 4 段连震
  - 每段间隔 `100ms`

- `SplitThreeWay`
  - 调用 `PlayExtraBalls()`
  - 2 段连震
  - 每段间隔 `150ms`

### 4.3 防抖与平台判断

`HapticController` 还做了两层保护：

- 同一帧只允许触发一次震动，避免一帧里被多次结算刷爆
- 只在移动端手持设备上启用

平台处理方式：

- Android：优先调用系统 `VibrationEffect`
- 其他移动端：走 `Handheld.Vibrate()` 兜底

## 5. 当前体验总结

按当前配置，玩家实际感受到的是：

- 单个或少量普通碰撞：不震
- 连续打掉 2 个以上砖块：会有一次轻到重的瞬时震动
- 横炸 / 竖炸：明显的四连震
- 三向分裂：较轻的双连震

## 7. 后续可调项

如果后面要继续调手感，最直接的入口有这些：

- 调低普通震动强度：改 `ScreenShakeConstants.BaseHapticIntensity / MaxHapticIntensity`
- 调短或调长震动：改 `HapticController.Play(float intensity, float sharpness)` 里的时长映射
- 让某类特殊块不震：改 `ScreenShakeController.PlayHapticForImpact`
- 接设置页开关：直接调用 `FeedbackSettings.IsScreenShakeEnabled` 和 `FeedbackSettings.IsVibrationEnabled`
